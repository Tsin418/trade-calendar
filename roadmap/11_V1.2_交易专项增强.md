# 11｜V1.2：交易专项增强

## 1. 版本目标

在通用事件日历稳定后，增加直接服务日本、韩国、台湾和香港股指期货交易准备的市场结构、公司财报和事件结果数据。

建议周期：4～6 周。

## 2. 进入条件

- MVP 和 V1.1 运行稳定；
- 目标交易所和指数来源已经确认；
- Watchlist 已经收敛；
- Actual、Consensus、Previous 的数据许可和访问方式已确认。

## 4. 需要实现的目标

- 四地交易日历能够用于日常开盘准备；
- 期货到期和结算事件不会因节假日产生错误日期；
- 指数公布日和生效日不会混为同一事件；
- 重点公司财报可以按市场和行业筛选；
- 结果数据能够正确处理修正值；
- 重要性评分可以被解释和人工覆盖。

## 5. 交付物

- 四地交易所日历 Adapter；
- 期货合约与到期配置；
- 指数调整来源；
- 扩展公司 Watchlist；
- 财报和电话会数据；
- 结果数据模块；
- 重要性评分模块；
- 专项测试和数据质量报告。

## 6. 验收标准

- [ ] 四地休市与特殊交易时间抽查正确；
- [ ] 目标期货合约到期日抽查正确；
- [ ] 节假日调整测试通过；
- [ ] 指数公布和生效事件正确区分；
- [ ] Watchlist 财报可按市场筛选；
- [ ] TBA 财报不会伪造时间；
- [ ] 结果修正会形成版本；
- [ ] 评分理由和人工覆盖正确；
- [ ] 不包含自动交易或确定性预测。

## 7. 主要风险

- 交易所和指数数据存在授权限制；
- 合约规则可能临时调整；
- 不同市场对最后交易日和结算日定义不同；
- 财报日期经常改期或先由第三方预计；
- 结果数据修正处理复杂；
- 自动评分可能高估普通事件。

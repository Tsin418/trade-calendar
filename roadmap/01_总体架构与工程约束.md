# 01｜总体架构与工程约束

## 1. 架构目标

架构需要优先保证以下能力：

- 事件来源和原始内容可追溯；
- 多来源事件可以合并；
- 改期、取消和字段修改可追溯；
- 抓取、解析、提醒失败不会静默；
- 人工修改可以覆盖自动同步；
- 所有任务可重复执行且不会产生重复数据；
- 个人服务器能够低成本长期运行。

## 2. 技术栈

```text
Web：Next.js + TypeScript + Tailwind CSS + FullCalendar
API：FastAPI + Pydantic + SQLAlchemy + Alembic
Worker：Python + APScheduler
Database：PostgreSQL
HTTP/Parsing：httpx + selectolax/BeautifulSoup + feedparser + icalendar + PyMuPDF
Testing：Pytest + Vitest + Playwright
Deployment：Docker Compose + Caddy
Notification：飞书 Webhook
```

MVP 不引入 Redis、Celery 和复杂消息队列。任务通过 PostgreSQL Advisory Lock 避免重复执行。

## 3. 系统模块

```text
Official Sources
      ↓
Source Adapters
      ↓
Raw Snapshots + Source Observations
      ↓
Validate → Normalize → Match → Reconcile → Version
      ↓
Canonical Events in PostgreSQL
      ↓
REST API ── Web UI
      ├── Reminder Worker ── Feishu
      └── Private ICS Feed
```

## 5. 关键数据实体

- `events`：系统对外展示的标准事件；
- `source_observations`：某个来源实际观察到的事件；
- `event_sources`：标准事件与来源之间的关系；
- `event_versions`：每次标准事件变更后的完整版本；
- `event_changes`：面向提醒和 Changes 页面的差异记录；
- `event_field_locks`：人工锁定的具体字段；
- `raw_snapshots`：原始响应、内容 Hash、解析器版本和保留期限；
- `sources`：数据源注册、优先级、频率和健康状态；
- `fetch_runs`：每次抓取和解析的运行记录；
- `alert_rules`：提醒规则；
- `notifications`：待发送和已发送通知；
- `review_queue`：冲突或低置信度候选事件；
- `audit_logs`：人工操作记录。

## 6. 不可违反的数据原则

### 时间

- 数据库存储 UTC 时间，同时保存原始时区和原始时间文本；
- 只有日期的事件单独保存日期，不能伪造成 `00:00`；
- `date_precision` 必须参与显示、去重和提醒；
- DST 和跨日转换必须有测试。

### 来源

- 正式事件必须有来源；
- 人工事件必须明确标记为人工来源；
- 来源冲突不能静默覆盖；
- 原始快照必须能关联到抓取运行和解析器版本。

### 变更

- 标题、时间、状态、重要性、结果或来源变化都要形成版本；
- 改期必须更新原事件，不能生成一个看似无关的新事件；
- 通知必须关联事件版本；
- 人工字段锁拥有最高优先级。

### 删除

- 来源单次返回 0 条不能删除历史事件；
- 自动同步优先软删除或标记缺失；
- 只有确认取消或人工操作才能改变事件正式状态。

## 7. API 与任务约束

- API 输入和输出使用明确 Schema；
- 所有写操作要具备幂等性或冲突保护；
- 手动同步立即返回任务 ID，不阻塞 HTTP 请求；
- Worker 任务必须有开始、结束、状态、错误和统计信息；
- Adapter 不能直接修改标准事件表，只输出来源观察结果；
- 敏感字段不能出现在日志和 API 响应中。

## 8. 安全约束

- 生产环境必须使用 HTTPS；
- 密码、Webhook 和 API Key 使用环境变量或加密存储；
- 数据库端口不对公网开放；
- 后台写操作需要认证和 CSRF 防护；
- 对手动同步和验证接口进行限流；
- 日志对凭据、Token 和个人配置脱敏；
- 备份至少保留 30 天。

- [ ] 数据实体和关系已经评审；

# MVP 产品与数据设计基线

## 默认用户配置

- 单用户、中文界面，原标题在详情和提醒中并列展示。
- 默认时区 `Asia/Shanghai`，支持 IANA 时区切换。
- 关注市场：美国、日本、韩国、台湾、香港及有限全球事件。
- 桌面端最低宽度 1024px；移动端最低宽度 360px；核心浏览和编辑流程均可用。
- 原始快照默认保留 90 天；正式事件与版本历史长期保留。
- 个性化 Watchlist 和提醒规则见 `config/`，上线前由用户复核。

## 页面线框

```text
┌─ 左侧导航 ─────┬────────────────────────────────────────────┐
│ Dashboard      │ 日期 / 时区        搜索     立即同步       │
│ Today          ├──────────┬──────────────┬─────────────────┤
│ Tomorrow       │ Next     │ Today        │ Source health   │
│ Week           │ Critical │ count        │ healthy / stale │
│ Month          ├──────────┴──────────────┴─────────────────┤
│ Changes        │ 今日时间线：已发生 ─ 下一事件 ─ TBA       │
│ Sources        ├───────────────────────┬───────────────────┤
│ Settings       │ 明日 / 本周重点       │ 最近变更          │
└────────────────┴───────────────────────┴───────────────────┘
```

Today/Tomorrow 使用按时间排序的高密度列表，已发生、未发生、TBA 分区。Week 默认列表视图并可切换周历。Month 单元格仅显示 Critical/High 与数量摘要，点击日期打开当日抽屉。

```text
事件详情 Drawer
┌──────────────────────────────────────────────┐
│ 中文标题                         [High] [TBA] │
│ 原始标题 / 机构 / 国家 / 影响市场             │
│ 用户时间、原始时间、时区、精度、参考期         │
│ 来源链接、最后核验、个人备注、提醒开关         │
│ [编辑] [忽略] [重新核验] [字段锁定]           │
│ 版本时间线：新增 → 时间补充 → 改期             │
└──────────────────────────────────────────────┘
```

Sources 展示状态、连续失败、上次成功、事件数量和运行详情；Settings 管理时区、Watchlist、提醒、ICS Token 与快照保留期。

## 时间规则

1. `minute/hour/window` 保存 UTC 时间、IANA 原始时区和原始文本。
2. `date` 保存事件当地日期；来源给出日期范围时，同时保存包含首尾的 `date_range_start/date_range_end`。不创建午夜时间，也不产生分钟级倒计时或提醒。
3. `unknown` 不要求日期；如果只有日期已知则搭配 `tba`。
4. 跨日窗口同时保存 `starts_at` 和 `ends_at`；展示时使用用户时区并保留原时区。
5. 时区转换只使用 IANA 数据库，DST 边界进入固定回归测试。

## 范围约束

P0/P1/P2 与明确不做项沿用 `roadmap/00_项目范围与成功标准.md`，不在开发过程中临时扩张。公司财报自动接入、动态网页发现和交易专项分别留在 V1.1/V1.2。

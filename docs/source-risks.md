# 数据源风险清单

| 风险 | 影响 | 处理 |
|---|---|---|
| 官方 HTML/PDF 结构变化 | 解析失败或字段缺失 | 保存快照、解析器版本、Fixture；字段完整率异常告警 |
| 年度日历 URL 变化 | 来源变旧 | 注册入口页而非只存年度文件；Stale 告警 |
| 来源限流或反爬 | 抓取失败 | 低频请求、条件请求、退避，不绕过访问限制 |
| BLS 官方站对运行网络返回 403 | 美国就业/通胀日程缺失 | 使用已授权长桥宏观日历作为次级源，TradingView 作为降级方案；关键日期仍可人工核验 BLS |
| Longbridge Docker OAuth 卷丢失或撤销 | 宏观日历认证失败 | 令牌仅存 `longbridge_auth` 卷，最小权限授权；失败可见并通过设备 OAuth 重新授权 |
| 官方事件仅给日期 | 错误提醒 | 使用 `date`/`tba`，禁止伪造午夜时间 |
| 不同来源标题和时区不同 | 重复或误合并 | 来源 ID 优先，机构/类型/参考期/日期辅助，低置信度进审核 |
| 单次返回空列表 | 历史数据被误删 | 空结果视为异常，不删除历史事件 |
| 韩国发布计划页面结构变化 | 韩国宏观覆盖不足 | 使用国家数据处全年发布计划入口；保留原始韩文标题、快照与来源归属 |
| HKEX 数据再分发限制 | ICS 或快照合规风险 | 上线前确认条款，仅存事件事实和来源链接；不与允许注明来源后复用的香港 C&SD 统计资料混同 |
| 第三方补充来源接口或许可变化 | 无法长期作为正式证据 | 仅作低优先级预计来源，保留归属与原始快照；由官方来源或已授权长桥确认后接管 |
| Finnhub 免费套餐不开放国际市场 | 非美本地代码缺失 | 使用 ADR/OTC 别名作为预计来源，并由交易所/IR 来源确认 |
| Finnhub 全市场财报响应截断 | 大型公司可能从批量结果遗漏 | Watchlist 逐公司请求，不使用无分页的全市场响应 |
| JPX 免费预定表不含具体时刻 | 日本财报只能确认日期 | 保持 date-only；公司 IR 公布电话会时间后另建 `earnings_call` |
| KIND/TWSE 当期无目标公告 | 正常空窗口被误报故障 | 允许目标型公告来源成功返回 0 条，但保留抓取运行和健康记录 |
| 财报发布与电话会不是同一时刻 | 错误分钟提醒 | 分为 `earnings_release` 与 `earnings_call`，不从盘前/盘后伪造时间 |
